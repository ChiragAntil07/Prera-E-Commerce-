# Prera E-Commerce Store

This is a basic e-commerce website made for a JavaScript project. It fetches and displays product data from a public API.

# Project Purpose

The purpose of this project is to build a simple product listing website using HTML, CSS, and JavaScript. It demonstrates API integration and responsive UI design.

# Public API Used

- DummyJSON Products API
- Link: https://dummyjson.com/products

# Features

- Fetch products using `fetch()`
- Show products dynamically on the page
- Responsive layout for mobile and desktop
- Loading and error message handling

# Technologies Used

- HTML
- CSS
- JavaScript
- DummyJSON API

# How to Run

1. Download or clone the project folder.
2. Open `index.html` in your browser.
3. Make sure your internet connection is on because the API data is fetched online.
